Three calls from upload to decision.

A REST API with TypeScript and Python SDKs. Create a video, upload the file, get the decision by webhook.

Quickstart

Create an API key in Settings. The SDK reads it from ORMES_API_KEY.

1

Create the video

POST /v1/videos with the rubric and file details returns a signed upload_url.

2

Upload the file

PUT the raw bytes to upload_url, then POST /v1/videos/{id}/complete.

3

Get the decision

The video.decided webhook, or GET /v1/videos/{id}. The SDK’s upload() and waitForDecision() do all three.

import { Ormes } from "@ormes/sdk";

const qx = new Ormes(); // reads ORMES_API_KEY

const video = await qx.videos.upload("./v_88214.mp4", {
  rubricId: "rub_load_dishwasher",
  contributorRef: "c_4086",
});
const d = await qx.videos.waitForDecision(video.id);

d.decision;      // "reject"
d.reasons[0];    // hands_visible.below_min, 61% (min 80%)
from ormes import Ormes

Endpoints

EndpointDoes
POST/v1/videosRegister a video and get a signed upload URL. Optional external_id, contributor_ref, lab_outcome.
GET/v1/videosList videos, newest first. Filter by status and decision; cursor pagination.
GET/v1/videos/{id}A video with its decision, review and lab outcome.
POST/v1/videos/{id}/completeMark the upload finished and queue the analysis.
POST/v1/videos/{id}/reviewA reviewer’s final decision, with an optional note.
POST/v1/videos/{id}/lab-outcomeWhat the lab decided, used to measure precision.
GET/v1/rubricsList rubrics, latest version of each.
POST/v1/rubricsCreate a rubric (version 1).
PUT/v1/rubrics/{id}Save a new version. Old versions are kept.

Authentication: Authorization: Bearer orm_live_…. We store only a hash of each key.

The decision object

Every decision carries the result, the reasons, every measurement and the rubric version. Reason codes are stable; messages are written for people.

{
  "video_id": "v_88214",
  "decision": "reject",
  "reasons": [{
    "check": "hands_visible",
    "code": "hands_visible.below_min",
    "message": "Both hands were visible 61% of the time while handling objects (minimum 80%).",
    "effect": "reject"
  }],
  "checks": {
    "hands_visible": { "status": "fail", "measurements": { "both_visible_ratio": 0.61 } },
    "task_completed": { "status": "pass", "measurements": { "confidence": 0.88 } }
  },
  "rubric": { "id": "rub_load_dishwasher", "version": 3 },
  "engine_version": "0.1.0"
}

Webhooks

video.decided is sent when a decision is ready. Each request is signed with your webhook secret.

Ormes-Signature: t=1761062400,v1=5f2b…c9

// v1 = HMAC-SHA256(secret, `${t}.${rawBody}`)
import { verifySignature } from "@ormes/sdk";

const ok = await verifySignature(rawBody,
  req.headers["ormes-signature"], secret);
if (!ok) return res.status(400).end();

Verify every request

Compare in constant time and reject timestamps older than five minutes. Both SDKs do this for you.

Respond fast

Return any 2xx, then process. The decision is also available by GET, so a missed webhook never loses a result.

Secret shown once

Create the webhook in Settings; the signing secret is shown one time.
